# Project Init

> Gerador de projetos: escolha a stack no navegador e baixe o projeto pronto em .zip.

| | |
|---|---|
| **Tipo** | Projeto pessoal · ferramenta para desenvolvedores |
| **Meu papel** | Design e desenvolvimento completos |

## Sobre o projeto

Em vez de repetir a configuração inicial a cada projeto novo, a ferramenta monta o esqueleto com as escolhas feitas na interface (framework, linguagem, ORM, banco, autenticação, UI, deploy, editor e extras) e entrega o resultado compactado. O repositório também traz o `AGENT.md`, que descreve meus padrões de projeto.

## Funcionalidades

- Seleção de framework, linguagem, ORM, banco de dados, autenticação, biblioteca de UI e gerenciador de pacotes
- Geração do projeto no navegador e download em .zip
- Comando de instalação pronto para copiar após o download

## Stack

Next.js (App Router) · React · TypeScript · Tailwind CSS · JSZip · Biome

## Como rodar

Pré-requisitos: Node.js 20+ e npm.

```bash
npm install
npm run dev
```
